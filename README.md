# 📊 Power BI Sales Dashboard | Superstore Analysis

An interactive Power BI Sales Dashboard built to analyze retail sales performance, profitability, customer segments, products, regions, and shipping methods.
The project covers the complete data analysis workflow, from data cleaning and transformation to data modeling, DAX calculations, and interactive dashboard design.

## 🎯 Project Objective

The main objective of this project is to transform raw retail sales data into an interactive analytical solution that helps users:

Monitor key business performance indicators.
Analyze sales and profit trends.
Compare performance across regions and customer segments.
Identify top-performing products.
Analyze the impact of discounts on profitability.
Support data-driven business decisions.

🔄 Data Analysis Workflow
Raw Data → Data Cleaning → Data Transformation → Data Modeling → DAX → Visualization → Interactive Dashboard


🧹 1. Data Cleaning & Transformation

Data preparation was performed using Power Query, including:
Reviewing the dataset and identifying data quality issues.
Removing unnecessary or irrelevant rows.
Removing duplicate records.
Handling invalid values and errors.
Assigning appropriate data types.
Preparing date fields for analysis.
Transforming and organizing the data for modeling.
🏗️ 2. Data Modeling

A structured Data Model was created to support efficient analysis and accurate reporting.

Key modeling tasks included:

Creating a dedicated Date Table.
Establishing relationships between tables.
Applying Dimensional Modeling principles.
Identifying Dimensions and Measures.
Validating relationships and filter directions.
Building a model optimized for interactive reporting.
🧮 3. DAX Measures & Calculations

Custom DAX (Data Analysis Expressions) measures were created to analyze business performance.

Key Measures
Total Sales
Total Profit
Profit Margin %
YoY Growth %
Total Orders
Total Quantity
Average Discount
Running Total

Time-intelligence calculations were also used to analyze trends and compare performance across different periods.
